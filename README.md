# RE4 FEN Modern Python Tool

A fast, modern Python utility to extract and repack Resident Evil 4 `.fen` files (PS4/Switch). Bypasses QuickBMS limits, size restrictions, and manual HxD padding. Developed by 3rfaja (ARFAJA).

## Features
- Fast extraction and repacking of `.fen` files.
- Pure Python implementation.
- Simple batch script automation.

## How to Use
1. Run `RUN EXTRACT ALL FEN.bat` to extract files.
2. Run `RUN REPACK ALL FEN.bat` to repack files.
